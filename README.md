# 3dsToJoy
3DS as a PC controller over Wi-Fi.
## DISCLAIMER!!! AI was used to make the 3DS app cause I don't know how to code in C or C++. The PC app was made 100% by me. no AI was used for creating that app.

# Setup
1. Download 3dsToJoy.3dsx
2. Download 3dsToJoy.exe (not ready yet)
3. Open the app on your PC
4. Enter your computers IP Adress into the 3ds
5. It works!

# Compiling
You need to get devkit pro. In MSYS2 use "MAKE" to compile it.
